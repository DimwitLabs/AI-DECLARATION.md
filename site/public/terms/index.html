The API

The API is open, requires no key, and is offered on a fair-use basis. There is no published rate limit and no service level agreement.

Please do not hammer it. Cache what you can, and if you need volume beyond casual tooling, open an issue or run your own copy, since the source is in the repository. Traffic that threatens availability for everyone else may be rate limited or blocked.

The API is stateless. It stores nothing you send it and has no access to the Directory database. Validation results are advisory: a valid response means the file matched the specification at the time of the request, not that any claim inside it is true.

The Directory

The Directory lists public GitHub repositories that publish a declaration file, using only data GitHub already makes public. Listing is automatic. It is not an endorsement, an audit, or a certification, and no check is made on whether a declaration is accurate.

If you do not want your repository listed, open an issue and it will be removed. Removing the declaration file from your repository also drops it on the next scan.

The Reddit App

The AI-DECLARATION.md Reddit app reads public GitHub repository links from public Reddit posts and replies with what those repositories declare. It is subject to these terms and to Reddit's own developer and content policies.

Moderators install it at their own discretion and can turn it off at any time.
